# Integration Scenarios

## 1. Meeting to task flow
- Submit a transcript.
- Receive summary and action items.
- Verify task records and follow-up notifications are created.

## 2. Workflow to CRM update flow
- Trigger a workflow event.
- Verify the generated workflow plan.
- Confirm the CRM update payload is queued.

## 3. Reminder escalation flow
- Seed overdue tasks.
- Run reminder workflow.
- Confirm Slack and email escalation payloads are produced.
